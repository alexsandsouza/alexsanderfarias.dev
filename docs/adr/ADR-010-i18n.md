# ADR-010: Estratégia de Internacionalização (i18n)

- **Status:** Aceito
- **Data:** 2026-09-07
- **Decisores:** UX Specialist, SEO Specialist, Software Architect

## Contexto
O portfólio atende tanto a comunidade acadêmica e empresarial brasileira quanto a recrutadores, pesquisadores e eventos internacionais. É fundamental suportar múltiplos idiomas (`pt-BR` como língua primária e `en-US`), com rotas limpas, preservação de contexto na alternância e facilidade de extensão para outros idiomas (ex: espanhol).

## Decisão
Implementar internacionalização estrutural baseada em rotas com prefixo de sub-caminho:
1. **Estrutura de URL:** `/[locale]/...` (ex: `/pt/projects`, `/en/projects`).
2. **Negociação de Locale:** Middleware inteligente no Next.js detecta as preferências do cabeçalho `Accept-Language` e redireciona `/` para o idioma mais apropriado, tendo `pt` como padrão soberano.
3. **Dicionários Tipados:** Utilizar arquivos de mensagens JSON tipados pelo TypeScript (`src/shared/config/i18n/locales/pt.json` e `en.json`) sem dependências externas pesadas em runtime.
4. **Metadados SEO:** Geração automática de links alternativos `hreflang` e tag `<html lang="...">` correta para cada página.

## Alternativas Consideradas
1. **i18n puramente Client-Side (react-i18next com troca sem mudar URL):** Desastroso para SEO, pois indexadores não conseguem rastrear as versões em inglês de forma determinística.
2. **Subdomínios Distintos (`en.alexsanderfarias.dev`):** Aumenta complexidade de DNS, configuração SSL e dilui a autoridade de domínio perante motores de busca.

## Consequências
- **Positivas:** Indexação perfeita pelos buscadores para ambos os idiomas, links diretamente compartilháveis, arquitetura extensível para novos idiomas.
- **Negativas:** Exige sincronização de chaves de tradução entre os arquivos de idioma.

## Implicações de Segurança
- O middleware sanitiza rigorosamente o segmento `[locale]` permitindo apenas valores válidos do enum (`['pt', 'en']`), prevenindo ataques de path traversal.

## Implicações de Performance
- Os dicionários de tradução são importados no servidor sob demanda, sem carregar dicionários de outros idiomas no cliente.
